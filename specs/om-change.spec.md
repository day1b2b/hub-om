# OM 변경

업무 ID: `om-change`

회차의 담당 OM을 정하거나 바꾸는 업무. 업무요청 배정 폼, 운영 상세 화면, 관리자 DB 관리 화면에서 바꿀 수 있다.

## 규칙

- **R1** OM을 바꾸면 업무요청 담당자와 연결된 운영 회차 OM이 같은 값이 된다.
- **R2** 새 OM이 정해지면 Slack 업무요청 접수 스레드에 배정 댓글을 단다. 스레드 정보가 없으면 웹훅으로 단독 메시지를 보낸다.
- **R3** 같은 담당자로 다시 저장하거나, 미배정 값(빈 값·배정필요 등)으로 바꾸면 Slack 알림을 보내지 않는다.
- **R4** Slack 알림이 실패해도 저장한 OM 변경은 되돌리지 않는다.
- **R5** 권한이 없는 사용자는 OM을 바꿀 수 없고, 아무것도 바뀌지 않는다.
- **R6** OM 변경 요청은 활동 기록에 남는다.

## 입구

| 입구 | 화면 | 누가 |
|---|---|---|
| `PATCH /api/om-request/assign` | 업무요청 > 담당 OM 배정 | 파트 담당 관리자 |
| `POST /api/operations/[operationId]/drive-import/apply` | 운영 상세 > 담당 OM 수정 | 로그인한 팀원 |
| `PATCH /api/admin/database/cell` | 관리자 > DB 관리 > 회차 OM 칸 | 관리자 |

## 알려진 빈칸

- **R1 @ `PATCH /api/admin/database/cell`** — 관리자 DB 화면에서 OM 칸을 고치면 업무요청 담당자가 따라 바뀌지 않는다. 2026-10-12 기획 확인: 맞춰야 함. 후속 작업으로 고친다.
- **R2 @ `PATCH /api/admin/database/cell`** — 관리자 DB 화면에서 OM 칸을 고치면 Slack 배정 알림이 가지 않는다. 2026-10-12 기획 확인: 가야 함. 후속 작업으로 고친다.
