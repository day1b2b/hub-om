# 엑셀 초기 이관 계획

이 문서는 엑셀을 계속 원본으로 쓰지 않고, hub-om으로 운영 데이터를 옮기기 위한 초기 이관 기준입니다.

## 목적

현재 엑셀은 여러 원천에서 온 값을 수기로 모아둔 임시 통합 장소입니다.
MVP에서는 이미 모여 있는 엑셀 데이터를 활용해 hub-om의 초기 운영 데이터를 만들고, 이후 신규/수정/회고 데이터는 hub-om과 실제 원천 자동화로 대체합니다.

## 이관 범위

초기 이관에서 우선 보는 탭은 아래 두 종류입니다.

- `OM 배정`: 앞으로 운영 예정이거나 배정 판단이 필요한 건.
- `종료회고`: 종료 후 회고, 만족도, 결과보고서, 이슈/조치 내용이 담긴 건.

운영 현황 통합표는 표준 운영 데이터와 비교 검증하는 참고 원천으로 사용합니다.

## 이관 후 원본 기준

- 이관 전: 엑셀이 수기 통합 원천입니다.
- 이관 중: 엑셀 행을 표준 운영 데이터로 매핑하고 검토합니다.
- 이관 후: hub-om DB가 운영 관리 원본입니다.
- 자동화 후: Salesmap, Calendar, 만족도, Drive 등 실제 원천이 hub-om을 갱신합니다.

## 이관 절차

1. 엑셀 파일을 로컬 또는 관리자 화면에서 읽습니다.
2. 대상 탭의 헤더를 기준으로 필드를 매핑합니다.
3. 필수값이 없는 행, 날짜가 불명확한 행, 중복 의심 행은 `검토필요`로 분류합니다.
4. 저장 전 미리보기에서 신규/업데이트/검토필요 건수를 확인합니다.
5. 확인된 행만 DB에 저장합니다.
6. 원천 행 snapshot과 매핑 오류는 import 기록으로 남깁니다.

## 필드 분류

| 분류 | 예시 | 처리 |
| --- | --- | --- |
| 기본 운영 정보 | 기업, 과정명, 코스ID, 교육형태, 시작일, 종료일 | 초기 이관 후 실제 원천 자동화 대상으로 분류 |
| 배정 정보 | OM, LD | hub-om에서 직접 관리 |
| 운영 보강 정보 | 회차, 시간, 지역, 현장 투입 여부, 특이사항 | hub-om 입력/수정 대상으로 관리 |
| 종료 후 정보 | 만족도, 결과보고서, 이슈, 조치 내용, 회고 | 종료회고 데이터로 저장 |
| 비용/매출 정보 | 매출, 비용, 수익, 강사비, 운영비 | 실제 원천 확인 전까지 검토 대상으로 유지 |
| 링크 정보 | 드라이브, 강의관리, 결과보고서, 위키 | 링크 필드로 저장하되 자동 탐색은 별도 작업 |

## 공개 저장소에 남기지 않을 것

- 실제 엑셀 파일.
- 실제 행 값.
- 실제 고객사명, 담당자명, 강사명, 코치명.
- 실제 매출/비용/수익.
- 실제 링크, 문서명, 파일명.

## 완료 기준

- 엑셀 원천을 표준 운영 데이터로 변환하는 매핑 규칙이 있다.
- 저장 전 검토할 수 있는 신규/업데이트/검토필요 결과가 있다.
- 실제 데이터는 공개 저장소에 커밋되지 않는다.
- 이관 후 운영 현황 페이지가 DB 또는 로컬 표준 데이터 기준으로 동작한다.
