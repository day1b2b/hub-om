# DB 작업 안전 규칙

이 문서는 백업 운영 절차가 아니라, Claude Code가 DB에 영향을 줄 수 있는 작업을 할 때 지켜야 하는 최소 안전 규칙입니다.

구체적인 백업 운영 설정은 저장소 관리자가 저장소 밖에서 별도로 관리합니다.

## 원칙

- 운영 DB에는 백업 확인 없이 migration, 대량 수정, 원천 적재, 삭제 작업을 실행하지 않습니다.
- 실제 운영 데이터는 물리 삭제하지 않습니다.
- 실제 데이터 예시, 원천 파일, 원천 분석 문서, 백업 파일은 Git에 커밋하지 않습니다.
- DB 접속 정보와 백업 접속 정보는 Coolify secret/env 또는 별도 보안 저장소에서만 관리합니다.

## Claude Code가 멈춰야 하는 경우

아래 작업은 사용자가 백업 여부와 실행 범위를 명시하기 전까지 진행하지 않습니다.

- 운영 DB migration
- 운영 DB write-back
- 원천 데이터 적재
- 대량 update/delete
- 비용, 매출, 수익, 권한 데이터 변경
- 운영 DB 접속 정보 변경

## PR 또는 보고에 남길 것

DB에 영향을 줄 수 있는 변경에는 아래를 남깁니다.

- migration 포함 여부
- 운영 DB 쓰기 포함 여부
- 원천 적재 포함 여부
- 백업 확인 필요 여부
- 실행한 검증 명령
- 실행하지 못한 검증과 이유
