# 강사 계약 서명 진행상태 (모두싸인 연동)

운영현황 교육 상세 "강사 계약요청" 칸에 강사별 계약 단계를 보여준다.

```text
미요청 › 요청됨 › 발송됨 › 서명 중 › 서명 완료
                           └ 예: "OM·부서장 서명됨 → 데이원 서명 대기"  [OM ✓][부서장 ✓][데이원 대기][강사]
```

- 요청됨·발송됨 = 강사 계약 응답시트(코스ID × 강사, C열 계약 발송).
- 서명 중·서명 완료 = 모두싸인 문서 상태. 시트 F열 "최종완료"는 발송 처리 완료라 서명 여부로 쓰지 않는다.
- 서명 순서(역할 이름)는 계약 양식 순서다: 1 담당 OM → 2 부서장 → 3 데이원컴퍼니 → 4 강사.
- **읽기 전용**이다. 모두싸인·시트에 아무것도 쓰지 않는다(재발송·취소 같은 쓰기는 범위 밖).

## 읽는 시점

| 언제 | 무엇 |
| --- | --- |
| 매일 08:00·12:00 (Coolify 예약 작업) | 시트 전체 + 모두싸인 최근 180일 `(B2B)` 문서를 읽어 스냅샷을 새로 쓴다 |
| 교육 상세를 열 때 | 스냅샷만 읽는다(외부 호출 없음). 화면에 "모두싸인 11/03 12:00 기준" 표시 |
| "지금 새로고침" 버튼 | 시트 + 그 과정 강사 이름이 제목에 든 모두싸인 문서만 읽고, 스냅샷의 그 강사 칸을 덮어쓴다 |

스냅샷은 DB가 아니라 컨테이너 임시 디렉터리의 암호화 파일이다(원본은 시트·모두싸인에 있는 사본). 재배포로 사라지면 다음 교육 상세 열람 때 백그라운드로 한 번 다시 만든다. 위치를 바꾸려면 `INSTRUCTOR_CONTRACT_SIGNING_FILE`.

## 문서 매칭 (코스ID × 강사)

모두싸인 제목 앞 번호는 코스ID가 아니라서 아래 순서로 찾는다.

1. 시트 그 행의 강사 이메일(Q) = 모두싸인 서명자 중 이메일 서명 방식의 값. 이메일이 없으면 제목에 강사명이 들어간 문서.
2. 시트 타임스탬프(AE) 하루 전 ~ 90일 뒤에 만들어진 문서.
3. 같은 강사의 다른 과정 행과 후보가 겹치면 제목에 코스명(K)이 든 것으로 좁힌다.
4. 그래도 가를 수 없으면 추측하지 않고 "모두싸인 문서 확인 필요"로 표시한다.
5. 취소 후 재발송처럼 한 행에 문서가 여럿이면 취소되지 않은 가장 최근 문서.

이메일은 비교에만 쓰고 스냅샷·화면에는 남기지 않는다.

## 설정 (Coolify env)

| 이름 | 값 |
| --- | --- |
| `MODUSIGN_API_EMAIL` | API Key를 발급한 모두싸인 계정 이메일(강사 계약 문서를 볼 수 있는 행정·계약팀 계정) |
| `MODUSIGN_API_KEY` | 모두싸인 API Key |

둘 중 하나라도 비면 모두싸인 부분만 꺼지고, 화면은 "시트 … 기준 · 모두싸인 미연결"로 발송됨까지 보여준다.

### API Key 발급 (행정·계약팀 최고관리자)

1. 모두싸인 웹 → 통합 설정 → 워크스페이스 관리 → API 연동 → API Key → "API Key 생성하기".
   메뉴가 없으면 워크스페이스가 API 사용 승인 전이다 → 모두싸인 고객센터에 승인 요청.
2. 이름(예: `hub-om 읽기`), 만료 = 사용자 지정 최대(365일) 권장. 키는 생성 직후 한 번만 보인다.
3. 발급 계정 이메일과 키를 Coolify env에 넣고 재배포한다. 키를 채팅·문서에 붙여 넣지 않는다.
4. 만료일 전에 같은 절차로 새 키를 넣는다(만료되면 화면이 "모두싸인 미연결"로 돌아간다).

## Coolify 예약 작업

Coolify 앱 → **Scheduled Tasks**에 두 줄을 등록한다(강의 후속 알람봇과 같은 방식).

- Frequency: `0 23 * * *`(UTC = 한국 08:00), `0 3 * * *`(UTC = 한국 12:00). 작업 시간대를 `Asia/Seoul`로 지정할 수 있으면 `0 8 * * *`, `0 12 * * *`.
- Command:

```bash
wget -q -O - --header="Authorization: Bearer $SYNC_API_SECRET" --post-data="" http://127.0.0.1:3000/api/sync/instructor-contract-signing
```

`wget`이 없으면:

```bash
node -e "fetch('http://127.0.0.1:3000/api/sync/instructor-contract-signing',{method:'POST',headers:{Authorization:'Bearer '+process.env.SYNC_API_SECRET}}).then(r=>r.text()).then(console.log)"
```

응답 예: `{"ok":true,"modusignSynced":true,"contractCount":…,"signingMatched":…,"completed":…,"signing":…,"ambiguous":…}`.
관리자 계정으로 같은 주소를 브라우저에서 열면(GET) 마지막 동기화 시각과 건수만 보인다.

## 호출량

`GET /documents`는 모두싸인 고비용 API(분당 150·초당 5)다. 예약 작업은 100건씩 페이지를 넘기며 0.3초씩 쉬고 최대 30페이지에서 멈춘다. 버튼은 강사 1명당 최대 2페이지.
