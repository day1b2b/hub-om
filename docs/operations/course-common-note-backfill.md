# 과정 공통 메모 안전 반영

기존 회차별 메모를 유지하면서, 동일 과정의 회차별 값이 모두 같은 항목만 빈 과정 공통 메모에 반영한다.

## 판정 기준

- `특이사항 / 이슈`, `회고 (OM+LD)`, `메모`를 각각 독립적으로 판정한다.
- 비어 있지 않은 회차별 값이 하나뿐이면 자동 반영 후보로 본다.
- 서로 다른 값이 둘 이상이면 직접 확인 대상으로 남긴다.
- 이미 과정 공통 메모에 값이 있으면 덮어쓰지 않는다.
- 회차별 메모는 수정하거나 삭제하지 않는다.

## 실행

대상 환경의 `DATABASE_URL`을 확인한 뒤 먼저 조회 전용으로 실행한다.

```sh
npm run db:backfill:course-common-notes -- --dry-run
```

실제 반영은 현재 백업과 작업 시간대가 확인된 경우에만 두 확인 플래그를 함께 사용한다.

```sh
npm run db:backfill:course-common-notes -- --apply --backup-confirmed --maintenance-confirmed
```

출력에는 과정 수와 판정 수만 포함하며 메모 내용은 출력하지 않는다. 반영 후 dry-run을 다시 실행해 후보가 0건인지 확인한다.
