# hub-om 디자인 기준

화면을 새로 만들거나 고칠 때 이 기준을 따릅니다. 값은 모두 `src/app/globals.css`의 `:root` 토큰과 아래 표에 있는 것만 씁니다. 새 색·새 값을 만들지 않습니다.

대원칙
1. 새 색·새 값을 만들지 않는다. 아래 표에 있는 값만 쓴다.
2. 같은 역할은 같은 모양.
3. 한 면(패널·모달) 안의 글자는 왼쪽 시작선이 하나.

코치 화면(`.coach*`)과 공개 페이지(`.public-*`, `.legal-*`, 로그인)는 별도 디자인이라 이 기준의 일괄 적용 대상에서 뺐습니다.

## 1. 색

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--bg` | #fdfdfc | 페이지 바탕 |
| `--surface` | #ffffff | 패널·카드·모달 |
| `--surface-strong` | #f6f6f3 | 표 머리, 옅은 칩, 마우스 올림 |
| `--text` / `--muted` | #222322 / #74736e | 본문 / 보조 글자 |
| `--line` | #deded9 | 모든 1px 선 |
| `--primary` | #17202a | 주 버튼 |
| `--selected` | #203044 | 선택된 탭 |
| `--control-bg` | #fbfcfe | 보조 버튼·입력 바탕 |
| `--th-text` | #445160 | 표 머리·라벨 글자 |
| `--danger` / `--danger-bg` | #b42318 / #fdf1f0 | 오류 문구, 경고 상자, 삭제 버튼, 필수 표시 |
| `--highlight-bg` | #fff4b8 | 가장 중요한 안내 강조 바탕 |

상태 색 쌍(글자/바탕): 초록 `--green` 정상·완료·가능 / 호박 `--amber` 예정·주의 / 빨강 `--red` 상태 칩 전용(배정 필요·반납 지연) / 파랑 `--blue`·`--blue-bg`(#e8eff7) 정보·완료 / 보라 `--purple` 태그 / 회색 `--muted` 비활성.

빨강은 두 가지만: 상태 칩은 `--red`, 오류·경고·삭제·필수 표시는 `--danger`.

강조 바탕 위계: 노랑 `--highlight-bg`(가장 중요) > 호박 `--amber-bg`(주의) > 회색 `--surface-strong`(참고).

## 2. 글자

크기 6단계만: 20(페이지 제목) · 16(모달·큰 제목) · 14(본문) · 13(패널 제목·입력칸) · 12(버튼·표 칸·라벨·도움말) · 11px(표 머리·상태 칩).
굵기 3가지만: 400 본문 · 700 강조 · 800 버튼·표 머리.
예외: 아이콘 글리프(9px 이하), 디데이 큰 숫자.

## 3. 여백

- 본문 영역 좌우 20px(모바일 18px), 패널 사이 12px.
- 패널 제목 줄(`.section-title`, `.table-header`) 10×14, 패널 본문(`.section-body`) 14.
- 패널 자체는 여백 0. 문구·버튼을 패널에 바로 넣지 말고 `.section-body`로 감쌉니다.
- 모달 머리 14×18 / 본문 좌우 18 / 바닥 12×18, 머리·바닥에 구분선.
- 표 칸 8×10(촘촘한 표 6×10), 첫·끝 칸 좌우 14.
- 간격은 4 · 6 · 8 · 10 · 12 · 16에서 고르고 홀수 px는 쓰지 않습니다(1px 선 제외).

## 4. 모서리·그림자

모서리 6(작은 버튼) · 7(버튼·입력) · 8(패널·카드·모달) · 999px(상태 칩).
그림자 4단계: 없음(패널) / 표 `0 1px 2px rgba(15,23,42,.04)` / 드롭다운·토스트 `0 8px 24px rgba(15,23,42,.12)` / 모달 `0 18px 42px rgba(15,23,42,.18)`.

## 5. 버튼

| 종류 | 모양 | 크기 |
| --- | --- | --- |
| 주 버튼 | `--primary` 채움, 마우스 올리면 `--blue` | 높이 34 · 모서리 7 · 12px/800 |
| 보조 버튼 | `--control-bg` + `--line`, 마우스 올리면 파랑 선·글자 | 높이 34 |
| 작은 버튼 | 보조 버튼과 같은 모양 | 높이 28 · 모서리 6 |
| 취소 | 바탕·선 없음, 회색 글자(마우스 올려도 빨갛게 바뀌지 않음) | 높이 34 |
| 삭제(위험) | 흰 바탕 + 연빨강 선 + `--danger` 글자 | 높이 34 |
| 인라인 | 둥근 칩형, 회색 선·글자 | 높이 22 · 모서리 999 · 11px/700 |

한 화면(모달)에 주 버튼은 1개. 비활성은 투명도 0.5. 일반 화면에서 `.primary-action`은 쓰지 않습니다(로그인 화면용 44px 규칙이 걸림).

## 6. 닫기·확인·안내

- 모달 닫기: 머리 오른쪽 글자 버튼 「닫기」 + Esc. 입력 중인 모달은 바깥 클릭으로 닫지 않습니다.
- `×`(U+00D7)는 떠 있는 작은 위젯 닫기와 칩·검색어 지우기에만.
- 토스트: 처리 완료 문구만, 화면 위 가운데, 2.5초. 실패 문구는 그 자리에 남깁니다.
- 툴팁: 버튼 옆 정보 아이콘(ⓘ)에 마우스를 올리면 위쪽에 짧은 설명.

## 7. 모달

- 뒤 배경 `rgba(15,23,42,.42)`.
- 폭 4단계: 460(작은 확인) · 600 · 760(일반) · 1040(넓은 표).
- 쌓임 순서: 드롭다운 20 · 떠 있는 위젯 30 · 모달 100 · 토스트 110.
- 자동 기입 확인 창(계산서 발행 요청, 강사 계약요청)은 「안내 + 경고(`--danger`) + 대응표 + 취소/확인」 같은 틀을 함께 씁니다.

## 8. 상태 칩·입력칸·표·탭·빈 상태

- 상태 칩: 높이 20 · 모서리 999 · 11px/700, 색은 상태 색 쌍만.
- 입력칸: 높이 34 · 좌우 10 · 모서리 7 · 13px. 포커스는 `--blue` 테두리 + `0 0 0 3px rgba(45,102,166,.14)`. 라벨은 위쪽 12px/700 `--th-text`, 필수 표시는 `--danger`의 `*`.
- 표: 머리 11px/700 `--th-text` · `--surface-strong` 바탕, 칸 12px.
- 탭: 페이지 안 탭은 채움형 하나. 선택 시 `--selected` 채움 + 흰 글자.
- 빈 상태 2종: 패널 전체가 비면 가운데 큰 안내(`.empty-state`, 34×18), 일부가 비면 한 줄 안내(14px 시작선).
