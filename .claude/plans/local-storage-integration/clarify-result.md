# 범위와 수락 기준
사용자 승인: 통합 차단 항목 2, 로컬 운영 저장소의 개인정보 암호화와 creationReceipts 보존을 통합한다.
원래 체크아웃과 각 작업자 브랜치는 보존한다. 기준 커밋 82c208d385b812c773b1d43d14a20209d20b9621; 새 브랜치 시작 상태 clean.
요구사항: 전체 파일 암호화/AAD 유지, 기존 배열·operations 객체 읽기 호환, 생성/수정/삭제 후 receipt 보존, 동일 요청 재시도 중복 방지, 손상·복호화 오류 시 원본 불변, 0600, 단일 프로세스 동시 쓰기 직렬화.
제외: 브라우저 초안, PostgreSQL/MongoDB, 배정 감사 계약, 운영 데이터, 키, 배포, push/merge, 신규 의존성.
미정 사항 없음. 다중 프로세스 writer 보장은 기존 범위를 넘으며 명시적으로 미보장.
R1/R2/R4/R5/R6=true, R3=false: Level3. 단일 Task이며 전체 프로젝트 완료 아님.
