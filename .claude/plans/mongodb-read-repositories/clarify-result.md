# 재개 범위
명확성 4/4: 기존 운영 PG 유지, Mongo 조회 기능 호환/개인정보 암호화, 합성 검증 완료가 목표. 사용자는 필요한 개발을 다시 묻지 말고 진행하도록 승인했다. 추가 질문 없이 기존 결정을 적용한다.
R1/R2/R4/R5/R6 해당, R3 미해당: Level 3. 이 범위는 전체 이전 Wave의 일부이며 운영 전환 완료를 뜻하지 않는다.
총괄은 공통 store, 팀 담당은 roster, 코치 담당은 public/private 조회, 독립 검토자는 검증 기준과 최종 리뷰를 맡는다. 실데이터 복사 runner 준비는 별도 기록하고 배포/실행을 테스트와 구분한다.
