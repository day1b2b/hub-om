# 범위와 승인
사용자가 전체 Mongo 이전의 다음 구현·검증을 계속 승인했다. PG 운영을 유지하고 실제 데이터 복사는 검증 후 별도로 수행한다. 이번 Task는 코치 생성/수정/상태/소프트삭제, 팀 명단 조회·생성·수정, 강사 노트 읽기·부분 저장의 native repository 구현이다. 운영 factory·API는 아직 연결하지 않는다. 기존 API 계약·암호화·동시성·null 의미 보존이 성공 기준이다.
명확성 4/4, 이전 승인 재사용. R1/R2/R4/R5/R6=5, Level3. 새 의존성/업무모델/키/운영데이터/배포 변경 금지. TeamUser 기존 물리삭제는 이번 구현에서 차단하고 전환 gate로 남긴다. 내부 동시성 guard는 별도 준비·검증하는 shadow 전용 인프라다.
