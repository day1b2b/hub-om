# 독립 메타 검토 — Parfit

구조/객관성 부분충족, 실패변별 보완필수, 원본추적성 조건부충족. 구현착수는 plan-v2 보완후수락한다. 구현부재를제품결함으로판정하지않는다.

필수: (1) 원본SHA/함수→규칙→계획→C번호→fixture기대결과→실행증거추적표 (2) guard참여자/문서와barrier별허용결과 (3) 감사action/필드·부재null·actor, Number후반올림/overflow,sequence번호열예외의좁은정규화 (4) commit전/불명/ACK/Calendar실패/revalidation실패의raw·감사·HTTP·효과횟수표 (5) Calendar한번은API요청단위,재요청once-only아님,빈결과도동일옵션 (6) 정확port/scope/예산과native/주입구분. 우선순위는실패표→경쟁표→추적표/port다.

C6후속전체이전은이번승격Task완료조건과구분한다. HTTP400유지와commit후실패의저장반영은별도로판정해야한다. 독립원본은신규core를공유하지않는다. DB/파일/테스트실행없음.
